## 四、核心算法说明

### 1. 遗传算法 (GA)
- **用途**: 智能调度、订单分配
- **流程**: 初始化种群 → 适应度评估 → 选择 → 交叉 → 变异 → 迭代
- **效果**: 调度效率提升 95%

### 2. 蚁群算法 (ACO)
- **用途**: 路径优化、TSP 问题
- **原理**: 模拟蚂蚁觅食，信息素引导路径
- **效果**: 路径长度优化 15-25%

### 3. LSTM 时序预测
- **用途**: 需求预测、趋势分析
- **模型**: 长短期记忆网络
- **效果**: 预测准确率 85%+

### 4. Prophet 预测
- **用途**: 时序预测、节假日处理
- **优势**: 自动处理节假日效应
- **效果**: 与 LSTM 融合，准确率提升

### 5. RFM 客户画像
- **R (Recency)**: 最近一次购买时间
- **F (Frequency)**: 购买频率
- **M (Monetary)**: 消费金额
- **效果**: 客户价值分级，精准营销

### 6. P-中位选址
- **用途**: 仓库选址、网点规划
- **目标**: 最小化总加权距离
- **求解器**: PuLP + CBC
