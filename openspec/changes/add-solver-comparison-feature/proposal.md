# 求解器对比功能提案

**变更名称**: add-solver-comparison-feature  
**创建日期**: 2026-04-22  
**状态**: 待批准

---

## 背景

### 当前问题

物流路径规划系统目前支持多种求解器（OR-Tools、Gurobi、遗传算法等），但用户无法直观对比不同求解器的性能表现。

### 为什么需要这个功能

| 原因 | 说明 |
|------|------|
| **决策支持** | 帮助用户选择最适合的求解器 |
| **性能优化** | 了解不同求解器的优劣 |
| **教学演示** | 展示算法对比效果 |

---

## 目标

### 核心目标

1. **可视化对比** - 以图表形式展示不同求解器的性能指标
2. **实时对比** - 支持同时运行多个求解器并实时显示结果
3. **导出报告** - 生成对比报告供用户下载

### 非目标

- 不涉及新增求解器
- 不涉及求解器内部优化
- 不涉及自动选择最优求解器（后续功能）

---

## 范围

### 包含

- [ ] 前端：对比页面（表格 + 图表）
- [ ] 后端：对比 API 接口
- [ ] 数据：性能指标收集
- [ ] 可视化：雷达图、柱状图、时间线

### 不包含

- 自动选择最优求解器
- 历史对比数据存储
- 用户自定义求解器

---

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 求解器运行时间过长 | 用户体验差 | 添加超时限制和进度提示 |
| 多求解器并发资源占用 | 服务器压力 | 限制并发数量 |
| 图表渲染性能 | 页面卡顿 | 使用虚拟化和懒加载 |

---

## 成功标准

### 验收条件

- [ ] 用户可以选择多个求解器进行对比
- [ ] 对比结果以表格和图表形式展示
- [ ] 对比报告可导出为 PDF
- [ ] 对比任务支持取消和重试

### 性能指标

| 指标 | 目标 |
|------|------|
| 对比响应时间 | < 5 秒 |
| 图表渲染时间 | < 1 秒 |
| 并发求解器数量 | ≤ 3 |
